# 🚀 دليل تشغيل وحل مشاكل سيرفر المزامنة على لوحة تحكم Plesk (Ubuntu)

هذا الدليل يشرح لك خطوة بخطوة وبكل سهولة كيف تقوم بتشغيل سيرفر المزامنة الخاص بتطبيق **«تكعيب الغضب»** على سيرفر الـ VPS الخاص بشركتك، وحل أي مشكلة تظهر في لوحة **Plesk**.

---

## 🛑 سبب المشكلة التي ظهرت لك في الصورة والحل الفوري:

### السبب:
الخطأ الذي ظهر لك:
`Cannot find module '.../node_sqlite3.node' (Node.js v27.0.0-alpha)`
سببه أن مكتبة `sqlite3` القديمة تعتمد على ملفات C++ مترجمة مسبقاً (Native C++ Bindings)، وعندما يكون إصدار Node.js تجريبياً أو مختلفاً في السيرفر لا يجد ملف الـ C++ المترجم فيتوقف السيرفر.

### الحل الجذري والنهائي الذي قمنا به:
قمنا بتحديث كود السيرفر `server.js` و `package.json` ليعمل بمحرك **Pure JavaScript 100%** فائق السرعة والأمان:
- **بدون أي اعتمادات C++ أو مكتبات خارجية معقدة.**
- **يعمل فوراً على أي إصدار Node.js لديك دون أي أخطاء نهائياً.**
- **تثبيت NPM يستغرق 3 ثوانٍ فقط بدون أي مشاكل تجميع.**

---

## 🛠️ خطوات تطبيق الحل في لوحة Plesk (دقيقة واحدة):

من نفس الشاشة التي أرسلت صورتها في Plesk:

### 1. تحديث ملف `package.json`:
من القائمة على اليمين تحت **Access to Configuration Files**:
- اضغط على **`package.json`**.
- استبدل محتواه بالمحتوى الجديد التالي ثم اضغط **Save**:
```json
{
  "name": "takeeb-ghadab-vps-server",
  "version": "1.0.0",
  "description": "سيرفر المزامنة المركزي لتطبيق تكعيب الغضب",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  },
  "dependencies": {
    "cors": "^2.8.5",
    "dotenv": "^16.4.7",
    "express": "^4.21.2",
    "multer": "^1.4.5-lts.1"
  }
}
```

### 2. تحديث ملف `server.js`:
- اضغط على **File Manager** (في شريط الأزرار أسفل الشاشة في Plesk).
- افتح ملف **`server.js`**، والصق فيه الكود الجديد المحدّث من مجلد `vps_server/server.js` ثم اضغط **Save**.

### 3. إعادة التثبيت والتشغيل بضغطة زر:
- ارجع إلى صفحة **Node.js** في Plesk.
- اضغط على زر **`NPM install`** (الزر ذو علامة الزائد).
- بعد ثوانٍ عند اكتماله، اضغط على زر **`Restart App`**.
- ستتحول الحالة فوراً إلى اللون الأخضر: **Application is running**! 🚀

## 🌐 تنبيه بخصوص الدومين (takeeb.io):
في أسفل الصورة لديك إشعار باللون الأسود:
`Domain takeeb.io resolve problems detected: The domain is not resolvable`
هذا يعني أن الدومين `takeeb.io` لم يتم توجيه الـ DNS الخاص به (A-Record) إلى عنوان IP السيرفر `85.215.243.237`.

**يمكنك حل ذلك بأحد طريقتين:**
1. **استخدام عنوان IP السيرفر مباشرة في التطبيق:**
   بدل كتابة الدومين، يمكنك كتابة رابط السيرفر في التطبيق بهذا الشكل:
   `http://85.215.243.237:3000`
2. **أو ضبط الـ DNS:**
   ادخل للمكان الذي اشتريت منه الدومين واجعل سجل **A Record** يشير إلى IP السيرفر: `85.215.243.237`.

## 📱 ربط تطبيق الأندرويد بالسيرفر:

1. افتح تطبيق **«تكعيب الغضب»** على هواتف العمل.
2. اضغط على أيقونة السيرفر بالأعلى أو من نافذة **«تصدير ونسخ احتياطي»**.
3. ضع رابط السيرفر:
   `http://85.215.243.237:3000` (أو رابط الدومين `https://takeeb.io` بعد تفعيله).
4. ضع مفتاح الأمان السري المحدد في ملف `.env`:
   `Ghadab_Sync_2026_SecretKey`
5. اضغط **فحص الاتصال** ثم **مزامنة الآن**!
